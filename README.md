视频合并工具 1.0.0 安装包

文件：VideoMergeTool_Setup_1.0.0.exe（约 47 MB）
系统：Windows 10 / 11 64 位
权限：安装到当前用户目录，不需要管理员权限

一、安装
1. 双击 VideoMergeTool_Setup_1.0.0.exe。
2. 如果 Windows 提示“未知发布者”或被 SmartScreen 拦截：
   点“更多信息” → “仍要运行”。安装包没有数字签名，这是正常提示。
3. 等待进度窗口完成，提示安装成功后点“确定”。

安装位置：
    %LOCALAPPDATA%\Programs\VideoMergeTool
安装包已自带 ffmpeg，不需要另外安装。

二、使用
选中 2 个或更多视频 → 右键 → “合并所选视频”。
也可以：右键 → 发送到 → “合并视频”。
合并完成会自动关闭进度窗，输出文件在第一个视频所在文件夹，
文件名类似：合并_20261104_135728.mp4

三、顺序
默认按文件名自然排序（1、2、10 按 1、2、10 排）。
要指定顺序，给文件加 01_、02_ 前缀。

四、卸载
方法 1：Windows 设置 → 应用 → “视频合并工具” → 卸载。
方法 2：开始菜单 → 视频合并工具 → 卸载视频合并工具。
